PRODUCT IMAGE FILENAME FORMAT:
CODE_PRICE.extension

Examples:
S001_1499.jpg = Saree S001, ₹1,499
S002_1899.jpg = Saree S002, ₹1,899
J001_599.jpg = Jewellery J001, ₹599
J002_899.jpg = Jewellery J002, ₹899

S = Saree | J = Jewellery

To change a price, rename the file. Example:
S001_1499.jpg -> S001_1299.jpg
Delete the old file and upload the renamed file.

To add a product:
1. Rename the image as CODE_PRICE.
2. Upload it to the ROOT of the GitHub repository.
3. Wait for GitHub Pages to update.
4. Refresh the website.

No HTML or products.js editing is required.
Images without _PRICE will not appear.
